# AIDIS Lab 홈페이지

AIDIS Lab의 지도교수, 연구 분야, 프로젝트와 연락처를 소개하는 가볍고 관리하기 쉬운 홈페이지입니다.

## 목표

- 지도교수의 약력과 연구 분야를 소개합니다.
- 연구실의 주요 연구과제와 대외 성과를 기록합니다.
- 공식 연락처와 연구실 위치를 안내합니다.
- 처음에는 데이터베이스나 백엔드 없이 정적 파일만으로 간단히 운영합니다.

## 정보 구조

```
홈
├── 연구실 소개
├── 연구 분야
├── 지도교수
├── 구성원
│   ├── 재학생
│   └── 졸업생
├── 프로젝트·활동
└── 연락처
```

현재 모든 내용을 한 페이지에 담습니다. 제공받은 홍보 자료의 학부연구생과 랩원 정보는 제외했으며, 추후 당사자가 공개에 동의한 프로필만 추가합니다.

## 로컬에서 미리 보기

`index.html`을 브라우저로 직접 열거나, 이 폴더를 정적 서버로 실행하세요. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 콘텐츠 수정하기

- `index.html`의 지도교수, 연구 분야와 연락처를 최신 정보로 유지합니다.
- 구성원은 재학생과 졸업생으로 나누고, 각 그룹 안에서 입학 연도 또는 기수순으로 정리합니다.
- 프로젝트·활동 섹션에는 확인된 프로젝트만 추가합니다.
- 사진과 기타 정적 파일은 `assets/` 폴더에 넣습니다.

### 자료 준비 체크리스트

구성원 프로필에는 이름, 입학 연도 또는 기수, 재학·졸업 상태, 연구 관심사, 대표 프로젝트와 공개 링크를 사용합니다. 사진은 `assets/members/`에 저장하고 의미 있는 대체 텍스트를 작성합니다.

프로젝트는 제목, 진행 기간, 한 문장 소개, 대표 이미지와 결과물 링크를 기준으로 기록합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트 폴더를 배포하도록 설정되어 있습니다. 이후 사용자 지정 도메인을 연결할 수 있습니다.

## 저장소 운영 원칙

- 구성원 정보는 당사자의 공개 동의를 확인한 뒤 게시합니다.
- 콘텐츠 변경은 작고 명확한 풀 리퀘스트로 나누어 반영합니다.
- 접근 토큰, 비공개 연락처, 공개 전 연구 자료는 커밋하지 않습니다.
