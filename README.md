# AIDIS Lab 홈페이지

대전대학교 AIDIS Lab의 정적 홈페이지입니다. 별도 설치나 빌드 없이 GitHub Pages에서 운영합니다.

## 다른 PC에서 작업 이어가기

새 작업은 [AGENTS.md](AGENTS.md)의 규칙과 [CODEX_CONTEXT.md](CODEX_CONTEXT.md)의 현재 상태를 먼저 읽고 실제 파일을 대조합니다. 중요한 변경 후 컨텍스트 문서도 갱신합니다. 자료 대조 근거는 [CONTENT-AUDIT.md](CONTENT-AUDIT.md)에 있습니다. Git으로 옮길 때는 미추적 파일을 포함한 커밋·원격 반영 여부를 확인하고, USB로 옮길 때는 프로젝트 폴더 전체를 복사합니다. 원본 참고 PPT는 프로젝트 밖에 있으므로 필요 시 별도 전달해야 합니다.

## 페이지 구성

- `index.html`: 홈과 주요 페이지 안내
- `about.html`: 연구실 소개
- `professor.html`: 기본 정보, 학력, 경력, 주요 연구 분야, 진행·완료 연구, 대표 논문
- `research.html`: 데이터 분석 및 인사이트 도출 / 인공지능 모델 연구 / AI 기반 소셜 플랫폼 개발
- `members.html`: 재학생·졸업생 프로필, 문의 안내
- `contact.html`: 연구실 위치, 지도교수 이메일과 유선전화
- `activities.html`: 활동 목록·유형 필터
- `activity-kpaas.html`: K-PaaS 수상 상세
- `member-*.html`: 가상 구성원 4명의 개인 상세

메뉴 순서는 홈 → 소개 → 지도교수 → 연구 → 구성원 → 활동 → CONTACT입니다. 홈 메뉴와 AIDIS LAB 로고 모두 메인 페이지로 연결됩니다. 기존 /#about, /#professor, /#research, /#members, /#projects, /#contact 링크는 navigation.js에서 해당 페이지로 연결합니다. 프로젝트 기록은 professor.html#projects에 있습니다.

## 로고와 스타일

assets/aidis-mark.svg는 A 형태에 데이터 노드와 연결선을 결합한 전용 로고입니다. 헤더, 푸터, 파비콘에 적용했습니다. 네이비·청록 색상을 유지하며, 공유 미리보기는 인물 사진이 없는 assets/og-aidis-lab.png를 사용합니다.

스타일은 styles.css, content.css, pages.css 순으로 적용합니다. 공통 메뉴를 수정할 때는 전체 HTML(현재 12개) 파일에 동일하게 반영합니다.

## 지도교수 자료 기준

[대전대학교 컴퓨터공학과 교수소개](https://www.dju.ac.kr/comeng2/depart/profileView.do?mi=2199)에서 박건우 교수의 상세보기를 선택합니다. 상세 주소만 직접 열면 선택 정보가 없어 내용이 비어 있을 수 있습니다.

- 학력·경력·논문·주요 연구경력: 공식 소개 기준
- 인공지능 영상 신뢰성 평가 표준화 연구와 K-PaaS 성과: 기존 연구실 제공 자료 기준
- ‘현재’ 경력과 오픈랩 상태는 공식 소개 표기를 따릅니다. 종료 여부와 신규 과제 기간은 자료 갱신 시 확인합니다.
- ‘지상전력시험평가과’, ‘군위성통신체계-Ⅲ’는 공식 페이지 원문 표기를 유지했습니다.
- 교수 연구실(융합과학관 3층 24323호)과 랩 공간(228호)을 구분합니다.
- 논문은 대표 6편을 표시합니다. 공식 소개 바로가기 링크는 요청에 따라 본문에서 제거했습니다.
- 연구과제 7건의 출처·중복 대조와 학생 성과의 구분은 CONTENT-AUDIT.md에 기록했습니다.
- K-PaaS 수상은 졸업한 학부연구생들의 성과로 CONTENT-AUDIT.md에 보존하며 활동 페이지에서 확인할 수 있습니다.

## 구성원 정보 수집과 교체

재학생/졸업생 탭은 선택한 그룹만 표시하며 기본값은 재학생입니다. 졸업생 성과는 구성원 화면에서 제외했으며 활동 페이지에서 확인할 수 있습니다. 탭 동작은 members.js에 있습니다.

현재 4명은 가상 예시이며 카드의 ‘예시 프로필’ 표기를 유지합니다. 실제 자료 수집 후 members.html의 person-card를 교체하거나 복사합니다. 기존 참고 자료에 있는 실제 랩원 정보는 사용하지 않았습니다.

수집 항목: 이름, 입학 연도, 재학·졸업 상태, 공개용 이메일, 기술 스택, 관심 분야, 사진, 경력·활동(기간/역할/기여/성과), 공개할 포트폴리오·GitHub 링크, 정보·사진 공개 동의. 기수·한 문장 소개·졸업 연도·현재 소속은 선택 항목입니다. 랩장에게 연락할 공개 수단이 제공되면 문의 페이지에 추가합니다.

- 사진은 assets/members/에 저장하고 이름을 대체 텍스트로 입력합니다.
- 실제 정보로 교체할 때 해당 카드의 ‘예시 프로필’을 제거합니다.
- 실제 링크가 제공되면 개인 상세페이지에 포트폴리오·GitHub 링크를 추가합니다.
- 재학생·졸업생 그룹 안에서 연도 또는 기수순으로 정리합니다.

## 미리보기와 배포

index.html을 열거나 이 폴더를 정적 HTTP 서버로 실행합니다. 모든 내부 링크와 파일 경로는 상대 경로입니다.

기존 GitHub Actions는 main 브랜치에 push할 때 사이트를 배포합니다. 로컬 파일 수정만으로 공개 사이트가 변경되지는 않습니다.

## 활동·소식·일정 등록

- 활동 목록: `activities.html`. 필터 분류는 `development`(개발), `competition`(공모전·수상), `presentation`(발표·공유). 카드의 data-category를 지정한다. 상세 페이지는 `activity-kpaas.html`의 공통 헤더·메타데이터·본문 구조를 참고하고 파일마다 제목·canonical·OG URL을 변경한다.
- 상세 취합 항목: 제목, 개인/팀 구분, 기간, 상태, 문제·목표, 진행 과정, 기술, 참여자별 역할·기여, 결과·성과, 공개 가능한 이미지와 GitHub/시연/발표 링크. 제공되지 않은 항목은 추정하지 않는다. 참여자는 실제 구성원 공개 승인 후 연결하며 예시 프로필에 성과를 연결하지 않는다.
- 메인 소식: `index.html`의 `.home-updates`에 공개할 소식 3건 이내를 최신순으로 등록하고 활동 상세 또는 공지 자료로 연결한다. 현재 수상 기록은 정확한 날짜 미제공으로 날짜를 생략했다.
- 예정 일정: `lab-updates.js`의 `labEvents` 배열에 `{ title, date, location, url }`을 추가한다. date는 `YYYY-MM-DD`, url·location은 선택값이다. 확정된 공개 일정만 등록한다. 한국 시간의 오늘을 포함한 미래 일정만 날짜순 최대 3건 표시하며 배열이 비면 빈 상태 안내를 표시한다. 과거 항목은 데이터에 남지만 메인에서 제외된다.
- 관리자/학생 직접 작성 화면은 없다. 정적 파일 수정 → 로컬 확인 → 승인 후 업로드 방식이다. 내부 이슈나 비공개 일정은 공개 저장소에 넣지 않는다.

## 구성원 상세 샘플

목록의 상세보기는 `member-kim-haneul.html`, `member-yun-seojin.html`, `member-park-doyun.html`, `member-lee-jian.html`로 연결됩니다. 모두 가상 예시이며 `assets/member-placeholder.svg`는 사진 자리입니다. 실제 교체 시 목록과 상세의 사진·입학 연도·기술 스택·관심 분야를 함께 갱신하고, 상세에 공개 이메일·경력(기간/역할/기여/성과)·실제 GitHub/포트폴리오 링크를 적용합니다. 미제공 선택 항목은 제거합니다. 공개 승인 후 예시 안내와 noindex를 제거하고 메타데이터도 실제 인물 기준으로 수정합니다. 연구실 활동 연결은 해당 인물의 실제 참여가 확인된 항목만 추가합니다.
